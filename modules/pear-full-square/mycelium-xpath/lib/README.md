# lib/

The parts of mycelium-xpath, a file each, imported by its `index.js`.

| file | |
|---|---|
| `query.js` | A query: standard XPath's forward part, phase 1 (README.md): steps by name, `*` and `.`; filters on a node's leaves; name(), starts-with(), contains(). |
| `xpath.js` | Navigate a tree by path. |
