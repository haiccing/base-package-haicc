# test/

The tests of mrepo-base-haicc, a section per file, each test by its name.

## `haicc.test.js`

- goto: at the root executed here; at a shortcut sent on; no command
- goto: a position inside main: the command executed there, the current root moved
- goto: a URI that selects: the command executed at each position, a list of what each gave
- goto: on from one shortcut at a time; what is left of the URI goes with the command
- goto: an mrepo by its registry reference: on as at the position the registry records it is linked
- haicc/script: the lines, each a simple command, run where the URI points; the request waits for them
