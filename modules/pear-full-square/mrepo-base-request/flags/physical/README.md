# physical

A command's URI read as its layer is stored: the reading without the flag, today.

`crud/read 'done/*/*/*' --flags layer=request physical` reads
`request/done` as it is stored: its folders by an offset's digits, a
record a file. With neither `logical` nor `physical` written, the
mrepo's setting says (`/runtime/xpath.json`, `reading`), physical where
it has none; written out, the flag says so whatever the setting.

## Declaration

An `option`, `chain`; it takes no value.
